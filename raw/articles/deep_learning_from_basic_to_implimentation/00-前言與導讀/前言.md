# 前言

歡迎閱讀此書。首先，請允許我簡單介紹一下這本書，並向那些幫助過我的人們致謝。

## 本書內容

如果你對深度學習（DL）和機器學習（ML）感興趣，那麼可以在本書裡找到一些適合你閱讀的內容。

之所以編寫本書，是為了幫助你瞭解足夠多的深度學習方面的技能，進而讓你成為機器學習和深度學習的高效實踐者。

讀完本書，你可以：

- 設計和構建屬於自己的深度學習網路體系；
- 使用上述網路體系來理解或生成資料；
- 針對文本、圖像和其他類型的資料進行描述性分類；
- 預測資料序列的下一個值；
- 研究資料結構；
- 處理資料，以實作最高效率；
- 使用你喜歡的任何程式語言和深度學習函式庫；
- 瞭解新論文和新理念，並將其付諸實踐；
- 享受與他人進行深度學習討論的過程。

本書會採用一種嚴肅而不失友好的講解方式，並透過大量圖示來幫助你加深理解。同時，我們不會在書中堆砌過多的程式碼，甚至不會使用任何比乘法更複雜的運算。

如果你覺得還不錯，歡迎閱讀此書！

## 為什麼寫這本書

本書的讀者對象是那些渴望在工作中應用機器學習和深度學習的人們，包括程式設計師、藝術工作者、工程師、科學家、管理人員、音樂家、醫生，以及任何希望透過處理大量資訊來獲得洞見或生成新資料的人。

你可以在許多開源函式庫中找到許多機器學習工具（特別是深度學習）。每個人都可以立即下載和使用這些工具。

儘管這些免費工具安裝簡單，但是你仍然需要掌握大量的技術和知識才能正確使用這些工具。讓電腦做一些無意義的事情很容易：它會嚴格照做，然後輸出更多無意義的結果。

這種情況時有發生。雖然機器學習和深度學習函式庫功能強大，但它們對使用者來說並不友好。你不僅需要選擇正確的演算法，還要能夠正確地應用這些演算法。從技術角度講，你仍然需要做出一系列明智的決策。當工作偏離預期時，你需要利用自己對系統內部的瞭解令其迴歸正軌。

學習和掌握這些基本資訊的方法多種多樣，這取決於你喜歡怎樣的學習方式。有些人喜歡詳細的硬核式演算法分析，並輔以大量數學運算。如果這是你的學習方式，那麼你可以閱讀一些有關這方面的書籍，比如 [Bishop06] 和 [Goodfellow17]。為此，你需要付出大量努力。不過，你獲得的回報也會很豐厚，即全面瞭解機器學習的工作方式及原理。如果以這種方式學習，那麼你必須額外投入大量的精力來將理論知識付諸實踐。

另外一種截然不同的情形是：有些人只想知道完成某些特定任務的方法。有關這方面的速成圖書也有很多，你可以從中找到各種機器學習函式庫，比如 [Chollet17]、[Muller-Guido16]、[Raschka15] 和 [VanderPlas16]。與需要大量運算的方法相比，這種方法難度較低。但是，你會覺得自己缺少對結構資訊的掌握——這些資訊有助於你理解演算法的工作原理。如果未能掌握這些資訊及相關詞彙，一些你原以為可行的演算法可能變得不可行，或者某種演算法的結果可能不如預期，而你很難對此找到問題的根源所在。另外，你將無法理解涵蓋新理念和新研究成果的文獻，因為這些研究往往假設讀者擁有相同的知識儲備，而只掌握一種函式庫或語言的讀者是不具備這種知識儲備的。

鑑於上述情況，本書採取了一種折中的方式。我們的目的很實際：給你工具，讓你有信心去實踐深度學習。希望你在工作的時候不僅可以做出明智的選擇，並且能夠理解日新月異的新理念。

本書致力於介紹深度學習的基礎知識，以幫助讀者建立扎實的知識儲備。隨著深度學習實踐的推進，你不僅需要對本書課題的背景有充分了解，還需要充分知悉可能需要查閱的資料。

這不是一本關於程式設計的書。程式設計很重要，但是會不可避免地涉及各個細節，而這些細節與本書的主旨並無關聯。此外，程式設計會讓你的思考侷限於某一個函式庫或者某種語言。儘管這些細節是構建最終學習網路體系的必要條件，但是當你想要專注於某一重要理念時，這些細節可能會讓你分心。與其就迴圈和目錄以及資料結構泛泛而談，倒不如以一種獨立的方式討論某種語言和函式庫相關的所有知識。只要紮實理解了這些理念，閱讀任何函式庫文件都將變得輕而易舉。

在第15章、第23章和第24章中，我們將詳細討論機器學習的 scikit-learn 函式庫以及深度學習的 Keras 函式庫。這兩種函式庫均基於 Python 語言。我們結合範例程式碼進行講解，以期讓你對 Python 函式庫有深度的瞭解。即使你不喜歡 Python，這些程式也會讓你對典型的工作流和程式結構有所瞭解。這些章節中的程式碼可以在 Python 手冊中找到，並且可用於基於瀏覽器的 Jupyter 程式設計環境 [Jupyter16]。你也可以將其應用於更經典的 Python 開發環境，如 PyCharm [JetBrains17]。

本書的其他大部分章節也有配套的可選 Python 手冊。這些章節針對書中每個電腦生成的數字給出程式碼，而且通常使用其中所涉及的技術來生成程式碼。由於本書的焦點並非在於 Python 語言和程式設計（上述章節除外），因此這些手冊僅作參考，不再贅述。

機器學習、深度學習和大資料正在世界範圍內產生令人意想不到的、快速而深刻的影響。對人類以及人類文化而言，這是一個既複雜又重要的課題。與此相關的討論也在一些有趣的圖書和文章中得以體現，不過結論大多是喜憂參半。相關的圖書和文章參見「參考資料」部分的 [Aguera y Arcas 17]、[Barrat15]、[Domingos15] 和 [Kaplan16]。

## 本書幾乎不涉及數學問題

很多人不喜歡複雜的方程式。如果你也是這樣，那麼本書非常適合你！

本書幾乎不涉及複雜的數學運算。如果你不討厭乘法，那麼本書簡直太適合你了，因為書中除了乘法，並無任何複雜的運算。

本書所討論的許多演算法都有豐富的理論依據，並且是經過仔細分析和研究得出的。如果你正打算變換一種演算法以實作新目的，或者需要獨立編寫一個新程式，就必須瞭解這一點。不過，在實踐中，大多數人會用由專家編寫的程式。這些程式是經過高度最佳化的，並且可以從免費的開源函式庫中獲取。

我們希望能幫助你理解這些技術的原理，掌握其正確應用，並懂得如何解讀結果，但無須深入瞭解技術背後的數學結構。

如果你喜歡數學或者想了解理論，那麼請閱讀每一章的「參考資料」部分給出的相關內容。大部分資料是簡潔且能夠激發靈感的，並且給出了作者在本書中刻意省略的細節。如果你不喜歡數學，可以略過此部分的內容。

## 本書分上下兩冊

本書涵蓋的內容非常多，因此我們將其分成了上下兩冊。其中下冊是上冊內容的拓展和補充。本書內容是以循序漸進的模式組織的，因此建議你先讀上冊，再去學習下冊的內容。如果你有信心，也可以直接從下冊開始閱讀。
