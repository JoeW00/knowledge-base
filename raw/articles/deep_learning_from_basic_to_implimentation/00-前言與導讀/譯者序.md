# 譯者序

深度學習（或稱深度神經網路）是一種使用了特殊分層計算結構的機器學習方法。近年來，深度學習在電腦視覺、語音辨識、自然語言處理和機器人等應用領域取得了驚人的突破。2019年3月27日，美國電腦協會（ACM）將「電腦界的諾貝爾獎」圖靈獎授予了3位深度學習之父（Yoshua Bengio、Geoffrey Hinton 和 Yann LeCun），以表彰他們給人工智慧帶來的重大突破——這些突破使深度神經網路成為計算的關鍵組成部分。這也意味著深度學習的神秘面紗至此已被揭開。

本書由電腦圖形學專家 Andrew Glassner 撰寫，介紹了深度學習的基礎知識和實踐深度學習的方法。全書分為上下兩冊：上冊介紹深度學習的預備知識，涵蓋基本的數學知識和機器學習的基本概念以及通用機器學習函式庫 scikit-learn 的相關內容；下冊深入介紹了各種成熟的深度學習方法和技術以及深度學習函式庫 Keras。

正如 Andrew Glassner 所描述的那樣，在本書英文版出版之前，市面上其實已出現了較多的深度學習相關的圖書。例如，由 Ian Goodfellow 等撰寫的 *Deep Learning* 一書，對演算法進行了非常詳細的分析，並給出了大量的數學運算；還有一類風格截然不同的書，例如由 François Chollet 撰寫的 *Deep Learning with Python*，主要是針對只想知道如何利用各種機器學習函式庫快速完成某些特定任務的讀者。本書介於這二者之間，主要介紹深度學習的基礎知識，以幫助讀者建立扎實的知識儲備，進而瞭解深度學習實踐的進展。Andrew Glassner 擅長以類比和圖示的方法講解複雜的理論知識，因此本書對不具備相關理論知識的讀者也會非常有幫助。

非常感謝人民郵電出版社的楊海玲編輯邀請我來負責本書的翻譯工作。回想自己首次接觸神經網路，已是10餘年前的事情了。在我學習神經網路時，市面上幾乎沒有類似的書，導致我走了不少彎路，也由此深刻感受到一本好書的重要性。在讀過本書英文版之後，我認為本書的出現正好填補了深度學習從入門到實踐的部分空白，於是欣然接受了本書中文版的翻譯邀約。

還要感謝參與本書翻譯的諸位同學：他們是上海交通大學密西根學院的王馨怡、付勇、何達、馮飛、樑子雲、李鑫路、駱昶旭和盧佳安。其中，何達和馮飛是我指導的直博生，王馨怡、付勇和樑子雲是我指導的碩士生，李鑫路、駱昶旭和盧佳安是我指導的高年級本科生。其中，王馨怡同學不僅參與了翻譯工作，還負責了翻譯協調的工作。在翻譯過程中，大家表現出的團隊合作與奉獻精神以及認真負責的態度都值得高度讚賞。可以說，本書是我們共同努力取得的成果，沒有他們的參與，本書的翻譯是不可能順利完成的。

我們將本書的翻譯分成了初稿翻譯、交叉驗證和審校3個步驟，以確保譯著的正確性和一致性。全書由我負責統稿和審校。但由於我們的中英文能力水平均有限，難免有翻譯不當之處，敬請廣大讀者批評指正。

最後，再次感謝人民郵電出版社給予的支援！
