## 1. 常見開源授權

從最寬鬆到最嚴格排列：

| 授權 | 寬鬆度 | 商用 | 修改後要開源嗎？ | 常見用途 |
|---|---|---|---|---|
| **MIT** | 最寬鬆 | 可以 | 不用 | 大量軟體專案（React、Node.js） |
| **Apache 2.0** | 很寬鬆 | 可以 | 不用，但要聲明修改處 | AI 模型（Qwen3、LLaMA 3）、Android |
| **BSD 2/3-Clause** | 很寬鬆 | 可以 | 不用 | FreeBSD、NumPy |
| **LGPL** | 中等 | 可以 | 只有修改該函式庫本身才要開源 | Qt、FFmpeg |
| **MPL 2.0** | 中等 | 可以 | 修改的檔案要開源，新增的不用 | Firefox |
| **GPL 2.0 / 3.0** | 嚴格 | 可以，但衍生作品也要 GPL | 要，整個專案都要開源 | Linux 核心、GCC |
| **AGPL 3.0** | 最嚴格 | 可以，但即使只是提供網路服務也要開源 | 要，連伺服器端也要 | MongoDB（舊版）、Grafana |

## 2. AI 模型常見的特殊授權

AI 模型圈還有一些不是傳統開源但常見的授權：

| 授權 | 說明 | 代表模型 |
|---|---|---|
| **Llama 3 Community License** | 免費商用，但月活超過 7 億用戶需另外申請授權 | LLaMA 3 |
| **Gemma Terms of Use** | 免費商用，但禁止用於生成違法內容，Google 保留限制權 | Gemma |
| **DeepSeek License** | 免費商用，但有使用限制條款 | DeepSeek-V3 |
| **CC BY-NC 4.0** | 可自由使用但**禁止商用** | 部分研究模型 |
| **Proprietary / API Only** | 不開源，只能透過 API 使用 | GPT-4、Claude |

## 3. 快速判斷

- 想商用且不想開源自己的程式碼 → 選 **MIT / Apache 2.0 / BSD** 授權的模型
- 看到 **GPL / AGPL** → 小心，你的整個專案可能也得開源
- 看到 **NC（Non-Commercial）** → 不能商用
- 看到大公司自訂的授權 → 仔細讀條款，通常有用量或用途限制
