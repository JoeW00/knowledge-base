# 對話式推薦 (Conversational Recommendation)

對話式推薦是一種透過多輪自然語言對話來理解使用者需求並提供推薦的系統範式。不同於傳統推薦系統的單次「輸入→輸出」模式，對話式推薦允許使用者在互動過程中逐步澄清偏好、修正方向、並探索新的推薦可能性。

## 從靜態推薦到動態對話

傳統推薦系統依賴使用者的歷史行為資料（點擊、購買、評分）來推測偏好，是一種被動式的靜態匹配。對話式推薦則主動向使用者提問、回應反饋、並根據對話脈絡動態調整推薦策略。這種模式特別適合：(1) 冷啟動場景——新使用者無歷史資料，但可以透過對話表達偏好；(2) 複雜需求——使用者的偏好難以用簡單的行為特徵捕捉（如「我想找一部適合全家週末一起看的電影，但不要太長」）。

## LLM 帶來的質變

LLM 的出現根本性地改變了對話式推薦的可行性與品質。早期系統依賴槽填充（slot filling）和意圖識別等 NLU 技術，對話能力有限且脆弱。LLM 能夠：流暢地理解自由形式的使用者輸入、維持多輪對話的上下文一致性、以自然語言生成推薦理由，以及整合世界知識來處理開放域的推薦請求。

論文將 LLM-based 對話式推薦分為三種方法論：(1) 提示與零樣本方法——直接用 LLM 的對話能力處理推薦；(2) 檢索增強方法——結合 [[rag]] 從推薦資料庫檢索候選再由 LLM 生成回應；(3) 行為對齊方法——透過微調讓 LLM 學習推薦領域的互動模式。

## 邁向推薦助手

對話式推薦正從「回答推薦相關問題的 chatbot」演化為「具備多輪推薦能力的個人化助手」——能記住使用者偏好、主動提供建議、處理跨領域需求（如從電影推薦延伸到餐廳推薦），並與其他工具整合（如行程規劃、價格比較）。這與 [[ai-agent]] 架構的發展方向高度一致。
