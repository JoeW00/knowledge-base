## Model Routing

Model Routing（模型路由）是根據查詢的特性與需求，將請求動態分配至不同 AI 模型或處理方案的策略，核心目標是在回應品質與成本之間取得最佳平衡。

### 動機

不同 AI 模型在不同任務上的性價比差異極大。簡單的事實查詢使用頂級大型模型是不必要的浪費，而複雜的推理任務交給小模型則可能產生不良結果。Model routing 的價值在於自動判斷每個請求的適當處理層級，將簡單查詢導向成本低廉的小模型，僅在必要時使用昂貴的大模型，從而在整體品質維持的前提下大幅降低平均成本。

### 路由策略

**基於規則的路由**是最直接的方式，依據查詢的長度、語言、類別等明確特徵設定路由規則。優點是透明可控，缺點是規則難以涵蓋所有情境。**基於分類器的路由**訓練一個輕量級分類模型來判斷查詢的複雜度或類別，再據此選擇目標模型。**基於 LLM 判斷的路由**使用一個 LLM 來分析查詢並決定最適合的處理模型，彈性最高但本身也產生推理成本。

### 成本-品質權衡

Model routing 的核心在於量化成本與品質的權衡。團隊需要建立評估基準，了解不同模型在各類查詢上的表現差異，並據此設定路由閾值。理想狀態下，routing 系統能將 70-80% 的請求導向便宜的小模型，只有真正需要的 20-30% 使用大模型，整體成本可降低 50% 以上而品質損失不到 5%。

### Cascade Routing

Cascade routing（串級路由）是一種特殊策略：先將請求送往小模型處理，並對輸出品質進行自動評估。若品質達標則直接返回，若不達標則自動升級至更大的模型重新處理。這種方式確保所有請求都先嘗試最經濟的路徑，只在必要時才使用更昂貴的資源。

### 與 AI Gateway 的整合

Model routing 通常建構在 [[ai-gateway]] 之上。Gateway 提供統一的模型存取介面與流量管理能力，routing 邏輯則作為 gateway 的策略層運作，根據每個請求的分析結果調用 gateway 將請求送往指定模型。兩者的整合使得多模型策略能在不增加應用程式複雜度的情況下運行。
