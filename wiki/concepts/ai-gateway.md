## AI Gateway

AI Gateway（AI 閘道）是一個位於應用程式與多個 AI 模型提供商之間的中間層，為不同模型提供統一的 API 介面，並集中處理存取控制、成本管理、負載均衡等跨模型的共通需求。

### 核心功能

AI gateway 的首要功能是提供**統一 API 介面**，讓應用程式無需針對每個模型提供商撰寫不同的整合程式碼，切換模型時只需更改配置而非修改應用邏輯。**訪問控制與配額管理**確保不同團隊或應用的 API 使用量受到合理限制。**成本追蹤**在中間層記錄所有請求的 token 用量與費用，提供跨模型的成本可見性。**負載均衡**在多個模型實例或提供商之間分配流量。**模型回退（fallback）** 當主要模型不可用時，自動將請求轉發至備援模型，確保服務穩定性。

### 開源方案 vs. 自建

市面上已有多個成熟的開源 AI gateway 方案。**LiteLLM** 支援超過 100 種模型提供商的統一介面，適合快速整合。**Portkey** 則提供更完整的可觀測性與 [[guardrails]] 整合。自建 gateway 的好處是可完全掌控邏輯，但需要投入大量維護成本。對於多數團隊而言，選擇成熟的開源方案並根據需求客製化是較務實的做法。

### 與 Model Routing 的關係

AI gateway 提供的是基礎設施層面的能力——統一介面、流量管理、監控追蹤；而 [[model-routing]] 則在 gateway 之上提供智慧調度邏輯，根據查詢的特性動態選擇最適合的模型。兩者協同運作：gateway 確保請求能送達任何模型，routing 決定請求應該送往哪個模型。

### 多模型策略的支撐

隨著模型生態越來越豐富，單一應用同時使用多個模型（不同任務用不同模型）已成為常態。AI gateway 是實現多模型策略的關鍵基礎設施，它消除了直接對接多家提供商的複雜性，讓團隊能專注於模型選擇與應用邏輯的優化。搭配 [[observability]] 工具，gateway 還能提供跨模型的效能對比數據，支援持續最佳化。
